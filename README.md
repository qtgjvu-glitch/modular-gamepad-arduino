# 🎮 雙手體感手把與模組化轉接系統 (Modular Controller System)

本專案為雙手遊戲控制器之硬體原型（Prototype）與驗證韌體。系統包含左手手把、右手手把，以及中央 I2C 訊號轉接板，具備完全模組化與物理防呆設計。

---

## 📌 系統架構與 I2C 設備配置

- **左手控制器**：
  - MPU-6050 姿態感測器 (I2C 位址: `0x68`)
  - PS2 雙軸搖桿 (X/Y 軸類比輸入 + SW 按鈕)
  - 專用 **5-Pin 模組化介面**
- **右手控制器**：
  - MPU-6050 姿態感測器 (I2C 位址: `0x69`，AD0 腳位拉高)
  - 4 鍵獨立微動按鈕 (ABXY，使用 Arduino 內建上拉電阻)
  - 專用 **6-Pin 模組化介面**
- **中央轉接模組 (Central Adapter Board)**：
  - 基於 Arduino UNO 進行電源分配與 I2C 總線匯流
  - 整合集線束帶與防拉扯機構 (Strain Relief)

---

## ⚡ 標準電源與操作規範 (防燒毀 SOP)

為保護敏感之 MPU-6050 MEMS 感測晶片，請嚴格遵守以下操作順序：

1. **嚴禁熱插拔**：拆裝任何模組排線前，務必先拔除 Arduino 的 USB/電源。
2. **通電順序**：接妥左右手排線與轉接板 $\rightarrow$ 插上 USB 供電。
3. **斷電順序**：拔除 USB 供電 $\rightarrow$ 拆卸排線。

---

## 🛡️ 物理防呆設計 (Poka-Yoke)

- 左手與右手排線介面採用 **5-Pin vs 6-Pin 不對稱插頭結構**。
- 物理尺寸差異可完全杜絕左右手插頭誤插或反插導致之電源短路風險。
